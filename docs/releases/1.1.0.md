# 1.1.0

**设置面板独立化**（破坏性改动：`6c4e102`）
不再撑高键盘，而是浮层卡片：圆角深色卡 + 分组、分隔线、彩色图标、右侧值 + `›`，全新风格等你体验。

**一页式设计**
版本号、恢复默认设置、项目网站全收入「关于」页面。

**自定义取色器**（`b9f4b50`、`60342f0`、`aa70f40`、`c181bbc`）
角色 chips + 24 色板 + 光谱 + 明度条 + `#RRGGBB` 色号 + 0-9A-F 小键盘，替换掉原来五行色块。

**随分辨率自动适配**（`da18c5e`、`bf98dae`、`b93dad4`、`2ee257a`）
五档尺寸按屏宽重算；卡片高度与左右位置由一次测量决定；布局管理器还没有主显示器时不再错误地 clamp。

**版权页重构**
「关于」里的作者酷安一行改用官方绿 CA logo，副标题只留「访问作者主页」，与项目网站、版本发布并列成三条外链。

**已知限制**（README 里已有）：面板位置不跟随重排；卡片内滚动在真手指上还没验证过（现在 1080 主列表已不需要下滑）。
